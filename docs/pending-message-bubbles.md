# 送信中の吹き出し

Agent Workspaceでは送信押下時に本文・出張先・添付名とサイズ・requestIdを固定し、会話末尾へ仮表示します。アップロード中／POST中／履歴照合中／送信結果不明／未送信を区別します。補足や待機キューへの送信もラベルで区別します。フォーム側の重複spinnerは廃止しました。

正式履歴との照合はAgent IDとrequestIdで行い、同文比較はしません。pollがPOST応答に先行しても仮表示を除去し、遅いPOST応答で復活させません。正式履歴側のqueued・awaiting_input・send_unknown等の表示はそのままです。サーバー保存とnative受付は区別します。

本文は押下時点で固定します。下書きの変更回数も記録するため、待機中に別の本文へ編集して元と同じ文章へ戻しても、その新しい下書きを消しません。添付と出張先は送信処理中は既存どおり編集をロックします。

仮表示は既存下書きと同じタブのsessionStorageに保持します。アップロード途中の再読込は未送信、POST途中の再読込は結果不明として復元し、自動再送しません。受付不明時の明示的な照合は保存した同requestId・同payloadを使用します。添付実体の下書きは既存IndexedDBを使用します。

## 境界

- 仮表示は各Agentの最新の送信試行1件です。確実に未送信だった失敗表示は次の送信試行で置換され、サーバーの会話履歴には登録しません。
- タブを閉じてsessionStorageを失った場合、仮表示は残りません。サーバーが受理済みの正式履歴は別途保持されます。
- 実Agent/通知先にはテスト送信していません。ブラウザ検証は隔離mockです。

## 表示の初期値

未設定時は役割アイコン・ダーク・文字サイズ中・メイリオ（端末にない場合sans-serif）、Markdownです。既存localStorageの有効な選択は上書きしません。報告モード・通知設定は変更しません。HTMLの既存ダーク初期値を維持し、会話CSSの初期font/scaleも同じ値にしています。
