# AI村の出発点

中心は状態遷移であり、その単位は「依頼」である。人間からAgentへの依頼も、Agentから別Agentへの委任も同じライフサイクルを持つ。委任は子依頼、実行・補足・再試行はその依頼に属するrunとして追跡する。Projectは分類であり、依頼の完了単位ではない。

人間は方向性を決め、Agentは仕事を遂行し、秘書は成果を人間に伝える。自然文の評価から成功や完了を推測しない。native実行の終了、結果の提出、受け手の判断、依頼の終了、外部通知はそれぞれ異なる事実である。

複数端末・複数コンピューターでの配置と仕事の受渡しを村の画面に表す。人間に毎回の結果受領クリックは要求しない。Agentの停止は依頼の取消とは別であり、不明な実行結果を自動再送して解決したことにしない。

現在のモデル・契約・移行は [共通依頼モデル](unified-request-model.md)、責務の分離は [目標設計](architecture.md) を参照。
