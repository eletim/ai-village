# AI村の出発点

## 思想

- 複数端末・複数コンピューターを前提とする。
- 各Agentは仕事を遂行できると信頼する。出力や手順を厳密に縛りすぎない。
- 人間は村長として方向性を決める。
- 誰が何をしているかを、村の人・建物・移動・成果の受け渡しとして可視化する。
- 秘書は工房との橋渡しを行い、成果を人間にわかりやすく翻訳する。

## 将来の構成案（未実装）

1. コアPCに秘書AIを置く。
2. 秘書がSSHで工房PCにアクセスし、PurpleMux CLIで人員を配置する。
3. 工房ごとに中心Agentを1体、サブAgentを0〜2体配置する。中心AgentへサブAgentへの指示方法を渡す。
4. 中心Agentの実行が終了すると秘書へ通知する。
5. 秘書が成果を確認する。問題があれば同じセッションを引き継ぎ、追加指示を行う。
6. 問題なく終了したら村長へのレポートを作成する。

まずはこの構成を接続せず、村のUIを磨く。画面から使い方や動きのイメージを育てていく。
