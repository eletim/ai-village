# AI村

AIたちの村で、人間が村長として方向性を決め、工房のものづくりを見守るプロジェクト。

最初の段階は **見た目と体験をつくるフロントエンドのプロトタイプ** です。村長の家、工房、村民、秘書の訪問、成果のお届けをゲーム風の画面で表現します。

## 起動

依存パッケージのインストールは不要です。Node.js 20以上を使用します。

```bash
npm run dev
```

http://localhost:5173 を開きます。ES Modulesを使うため、HTMLを直接開かずHTTPサーバーで表示してください。

```bash
npm run check
npm test
npm run build
```

ビルド結果は `dist/`。任意の静的ホスティングで配信できます。

## 画面でできること

- 斜め見下ろしの村を眺める。村長の家と3つの工房、9人の村民を配置。
- 秘書ミクへ自然文で依頼を伝える。
- 秘書の工房訪問、3人の配置、制作、リツによる成果の運搬、確認・報告のデモを見る。
- 工房をクリックして室内や担当者を覗く。村民をクリックしてプロフィールを読む。
- デモを最初から表示。スマートフォン向けレイアウトと動きを減らす設定に対応。

依頼や会話、作業結果はシナリオによるデモです。AIへの送信、SSH接続、PurpleMux操作、実際の制作は行いません。入力内容は送信・保存しません。

## 構成

- `src/scene.js` — SVGの村、建物、村民
- `src/simulation.js` — 依頼から報告までのデモ進行
- `src/main.js` — 操作、詳細パネル、会話、移動表示
- `src/styles.css` — 村の外観、室内、レスポンシブ表示
- `docs/concept.md` — AI村の思想と将来の構成案

外部パッケージは使用していません。フォントのみGoogle Fontsから読み込み、利用できない場合はシステムフォントに切り替わります。
